# Code of conduct

## Our standard

Contributors are expected to communicate with respect, assume good faith, and avoid harassment, discrimination, or sharing of sensitive pilot data in public channels.

## Scope

Project spaces including GitHub issues, pull requests, and discussions.

## Enforcement

Maintainers may moderate contributions that violate these expectations. Report concerns privately to the repository owner.

## Domain sensitivity

SquadRidge relates to conflict, mediation, and institutional trust. Do not paste real participant content, private room transcripts, or live credentials into public issues.
