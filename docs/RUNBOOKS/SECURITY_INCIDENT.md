# Runbook: Security incident

**Status:** Draft operational requirement

1. Assess severity (unauthorized data access vs availability)
2. Rotate exposed keys (anon if leaked in unexpected place; service role if exposed)
3. Disable public app access if needed
4. Preserve audit logs; do not destroy evidence
5. Notify affected institutional partners per agreement
6. Document timeline and remediation
7. Update truth matrix if a control failed

Do not claim detection capabilities that are not instrumented.
