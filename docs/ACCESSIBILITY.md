# Accessibility

**Purpose:** Current expectations and known work.

## Implemented baseline

- Focus-visible styles
- Semantic labels on key controls
- `aria-live` on dialogue regions in facilitator room
- Reduced-motion media query hardening in CSS
- Keyboard-clickable primary actions

## Required ongoing work

- Full keyboard path audit for all dialogs (pause, close confirm)
- Screen-reader pass on Spine and commitment lists
- Contrast verification for all semantic signal colors
- Mobile navigation audit for participant room

Accessibility is treated as institutional quality, not a late polish item.
