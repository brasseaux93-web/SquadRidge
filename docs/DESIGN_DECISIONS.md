# Design decisions

**Purpose:** Explain deliberate non-choices.

| Avoided pattern | Why |
|-----------------|-----|
| Generic blue SaaS cards | Undermines institutional seriousness |
| Consumer chat bubbles | Wrong mental model for mediated dialogue |
| Engagement metrics / streaks | Conflicts with dignity and pilot ethics |
| Military command aesthetics | Wrong domain signal |
| Fake encryption badges | Trust requires accuracy |
| Gamified progress confetti | Inappropriate for high-consequence work |
| Emotion/sentiment inference UI | Explicit product non-goal |

The Dialogue Spine, Protected Pause, and Commitment Card exist to make process structure and consent visible without surveillance framing.
