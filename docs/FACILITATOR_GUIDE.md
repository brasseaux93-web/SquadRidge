# Facilitator guide

**Purpose:** Practical guidance for running a room in the current product (primarily fixture demo).

**Mode:** Demo/fixture unless Supabase adapter and Auth are fully configured.

---

## Before you start

1. Read [TRUST_AND_LIMITATIONS.md](./TRUST_AND_LIMITATIONS.md).
2. Understand that demo role entry is not production authentication.
3. Tell participants what is retained and what is purged.

## Enter the demo

1. Open `/enter`
2. Choose **Facilitator**
3. You land on `/app` (workspace)

## Run a room

1. Open a room from the workspace list
2. Review **Dialogue Spine** (current stage)
3. Confirm ground rules / working agreements with participants
4. Guide conversation; messages appear under display roles
5. Propose commitments when shared understanding emerges
6. Approve only what should survive close
7. Use **Close room & purge chat** when finished (confirm dialog explains retention)

## Phase control

Use session phase controls to move among opening, dialogue, caucus, synthesis, closing. Participants should always be able to see where the process is.

## Pause / concern

Use or invite **Request pause / support**. Treat it as legitimate process care. Full backend notify path is still incomplete—have a human backup channel for real pilots.

## After close

- Messages are purged from the application store/tables
- Approved outcomes remain on the ledger view
- Do not represent demo ledger entries as formal institutional records without program agreement
